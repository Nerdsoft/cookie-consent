## Package structure

```
src/
  core.ts     ← all logic: config merging, cookie r/w, consent signals, ConsentManager
  react.tsx   ← useCookieConsent() hook + <CookieConsentBanner /> component
  index.ts    ← vanilla JS entrypoint: CookieConsent.init() / .destroy()
dist/         ← generated by tsup (ESM, CJS, .d.ts)
```

## Architecture

**`core.ts` is the single source of truth.** Both the vanilla and React entrypoints import from it — no logic lives in `index.ts` or `react.tsx` beyond wiring.

### Config resolution (`mergeConfig`)
User config is shallow-merged with defaults. Mode (`ccpa` | `gdpr`) drives smart defaults for `autoAcceptMs` and `autoAcceptOnScrollPx` — GDPR sets both to 0 (no auto-accept), CCPA defaults to 5000ms / 100px scroll. User values always win.

### ConsentManager (`createConsentManager`)
Stateless factory that reads/writes a single cookie (`storageKey`). Returns `{ getStatus, accept, decline, shouldShow }`. All signal firing (Bing UET, Google Consent Mode) happens inside `accept`/`decline`.

### React entrypoint
- `useCookieConsent(config)` — hook for headless usage; returns status + actions
- `CookieConsentBanner` — default UI; fully replaceable by consuming `useCookieConsent` directly
- GDPR mode renders a Decline button alongside Accept; CCPA mode renders a "Do Not Sell" link instead

### Vanilla JS entrypoint
`CookieConsent.init(config)` wires up auto-accept timers/scroll listeners and calls `manager.accept()`. Does not render any UI — callers are responsible for rendering their own banner and calling `CookieConsent` methods.

## Consuming in a React project

```tsx
// Drop-in default UI
import { CookieConsentBanner } from '@nerdsoft/cookie-consent/react';

<CookieConsentBanner config={{
  mode: 'ccpa',
  text: { message: 'We use cookies...' },
  links: { privacyPolicy: '/terms/#Privacy', doNotSell: '/terms/opt-out/' },
  behavior: { autoAcceptMs: 5000, autoAcceptOnScrollPx: 100 },
  signals: { bingUet: true },
  onAccept: () => { /* fire additional tracking */ },
}} />

// Headless — bring your own UI
import { useCookieConsent } from '@nerdsoft/cookie-consent/react';

const { isVisible, accept, decline, config } = useCookieConsent({ mode: 'gdpr' });
```
